The [standalone HTML reference source](README.html) is generated by [build_meter_readme.py](../../../tools/esp32/build_meter_readme.py) and embedded as `meter_readme_assets.h`. [Download the release HTML](https://github.com/siujacky/Esp32-s3-Bluetooth-datalogger/releases/download/v0.2.3/README.html) and open it locally, or use `/readme.html` on the device. The release download and device copy describe their firmware snapshot; the checked-in HTML follows the current source. After editing the generator, regenerate both artifacts and check them from the repository root:

```powershell
python tools/esp32/build_meter_readme.py
python tools/esp32/build_meter_readme.py --check
python tools/check_docs.py
node tools/esp32/check_meter_manual.cjs
```
