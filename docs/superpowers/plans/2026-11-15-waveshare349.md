# Waveshare 3.49 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task by task.

**Goal:** Build and package V1/V2 Meter Workbench firmware using LCD, touch, TF,
RTC and IMU.

**Architecture:** Dedicated panel backend and board-device service, selected by
validated JSON. Only the main loop owns auxiliary I2C; web reads copied state.

**Tech Stack:** Existing PlatformIO, Arduino 2, Adafruit GFX, SensorLib, FatFs.

**Spec:** [Board design](../specs/2026-11-15-waveshare349-design.md)

## Global constraints

- Keep existing target wiring and behavior; no connected-device mutations.
- N16R8 memory; QSPI mode3/40MHz, native panel 172x640.
- RTC UTC only; reject stopped/invalid time; NTP outranks browser/RTC.
- Normal TF mounts never format. Format only the owned physical drive.
- IMU rotation requires stable gravity; no flash write for motion events.

## Review focus

- Revision mismatch: separate packages and explicit physical identification.
- Bad clock after battery loss: reject OS flag and invalid BCD/calendar dates.
- Wrong touch axes or bad packet: corner tests and no output mutation on error.
- Display movement: debounce, flat/dynamic rejection and touch suppression.
- Slow/missing peripherals: timeouts, failure state and no network-thread I2C.
